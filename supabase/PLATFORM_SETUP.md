# إعداد مشروع University Platform الجديد

هذا المشروع منفصل تماماً عن قاعدة بيانات النتائج الحالية.

## ما الذي تنشئه الهجرة؟
- حسابات مسؤولي المنصة وصلاحياتهم في `platform_admins`.
- محتوى المنصة (محاضرات، تخصصات، مواد، أخبار، امتحانات، واجبات، إشعارات، جداول، اقتراحات) في `platform_content`.
- سجل تدقيق للإضافات والتعديلات والحذف في `platform_audit_logs`.
- مساحة ملفات خاصة `platform-files` للمحاضرات والمرفقات.
- سياسات RLS تمنع التعديل إلا للمسؤولين النشطين.

## خطوات التفعيل
1. أنشئ مشروع Supabase جديداً باسم **University Platform**.
2. افتح SQL Editor في المشروع الجديد فقط.
3. نفّذ محتوى الملف `supabase/migrations/202611150001_platform_admin.sql`.
4. أنشئ أول مستخدم من Authentication ثم انسخ UUID الخاص به.
5. نفّذ أمر bootstrap الموجود في نهاية ملف SQL بعد استبدال UUID.
6. لا تضع `service_role` key في ملفات الموقع. الواجهة تستخدم publishable/anon key فقط.

## تنبيه
هذه الهجرة لا تنشئ مستخدم Auth ولا كلمة مرور، ولا تعدل مشروع النتائج. لا تضع بيانات المشروع السرية في GitHub.
